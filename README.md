# WebDev-Pelisovellus
Ohjelmisto 2 kurssin peliprojelkti

Peli on platformer game eli tasohyppely peli.
Pelissä pelaaja kerää kolikoita ja etenee seuraavalle tasolle. 
Pelaajalla on myös elämäpisteet, joita voi menettää, jos ottaa vahinkoa.
Kun pelaaja on menettänyt kaikki elämäpisteensä, pelaaja "kuolee" ja pelattu taso alkaa alusta.
Tavoite on päästä läpi viimeinen taso.
